# Image 2 主题生成记录

日期：2026-07-28  
模式：Codex 内置 Image 2（`image_gen`），不是 CLI/API 回退。

## 统一产品约束

- 这是官方 Codex 宠物脚下的生产级 UI 素材，不是场景插画。
- 常规主题最终为 896×288，运行时显示为 224×72。
- Iron Throne 为特殊高背主题，最终为 896×384，运行时显示为 224×96。
- 顶部中央必须保留宠物落脚面。
- 前脸必须保留一块连续、深色、无遮挡的双指标区域。
- 图片自身不生成文字、数字、宠物、人物、Logo 或水印。
- 源图使用纯色 `#ff00ff` 背景，无地面、阴影、反射和背景渐变；本地去色键
  后保存为透明 PNG。
- 程序统一绘制 `WEEK LEFT`、`WEEK TOKENS`、进度线和实时数值。

## 最终提示词集合

### Princess Cradle

创建低矮宽幅的公主摇篮宠物底座：象牙白珐琅曲线、粉色天鹅绒浅软垫、
香槟金包边、少量珍珠和晶石；两端可轻微上扬，但不要高床栏、立柱或顶篷。
顶部中央是清晰落脚面，前脸中央是连续深梅紫/海军蓝玻璃仪表区。风格为精致
高级的 3D 游戏 UI 道具，轮廓简洁，缩到 224×72 仍可辨认。

### Forest Rune

创建古老森林祭坛底座：深色板岩平台、六至七块大体块圆石、克制的苔藓和
角落蕨叶、外侧石块上的青色抽象符文；顶部中央是炭黑落脚盘，前脸中央是
连续烟熏板岩玻璃仪表区。不要碎石堆和过密细节。

### Clockwork Brass

创建精密钟表机械底座：古铜、黄铜、深胡桃木、两侧少量大齿轮弧、铜管和
琥珀能量管；顶部中央是浅圆形落脚盘，前脸中央是连续深棕/海军蓝玻璃仪表区。
维多利亚机械感必须服务于缩略图可读性，装饰只留在外侧三分之一。

### Moon Lotus

创建月光莲台底座：月白瓷、淡青玉莲瓣、银蓝落脚盘、外侧少量新月嵌件和
青色光缝；前脸中央是连续靛蓝玻璃仪表区。气质宁静、精致、东方幻想化，
不要高背雕像或复杂透明材质。

### Sakura Shrine

创建低矮神社舞台底座：深色漆木、克制朱红梁边、黄铜榫接、外侧少量樱花，
侧面可有简化青海波纹；顶部中央是椭圆落脚盘，前脸中央是连续近黑靛蓝仪表区。
不要鸟居、屋顶、灯柱、树木或高背景。

### Iron Throne

创建 224×96 特殊高背王座底座：三层宽浅黑石阶、锻黑铁边与铆钉，中央有
清晰座面；后方由大量重叠铁剑形成高背剑阵。剑阵在肩部高度延伸到石台约
86% 宽，使约占底座 60% 宽的宠物覆盖中央后，左右仍能露出明显剑簇和肩后
剑尖。最下层前脸保留连续蓝黑金属/玻璃仪表区。只使用冷钢轮廓光和极少暗红
余烬，不添加人物、血迹、骷髅、纹章、旗帜或场景。

## 透明化与归一化

1. Image 2 在纯 `#ff00ff` 背景上生成源图。
2. 使用系统 imagegen Skill 的 `remove_chroma_key.py`，启用 border 自动取色、
   soft matte、despill 和 1px edge contract。
3. Princess Cradle 的粉色软垫与色键接近，因此只对被金边封闭的软垫和仪表
   内区恢复不透明 Alpha，不改变外轮廓。
4. 常规主题归一到 896×288；Iron Throne 归一到 896×384。
5. 在 224×72 / 224×96 实际尺寸叠加实时指标做视觉验收。

最终成品位于 `assets/themes/`；总览与真实客户端截图位于
`docs/screenshots/`。
